# Reporting Summary（Nature Communications）

本目录用于存放 Nature Communications 要求的 **Reporting Summary**（单独上传的 PDF）。

## 需要你做什么

1. 从 NC 官网下载最新模板并填写（模板可能会更新，以官网为准）。
2. 将填写完成的文件放到本目录，例如：
   - `reporting_summary.pdf`
   - 或 `reporting_summary.docx`（最终导出为 PDF）

## 填写要点（结合本稿）

- **Statistics**：列出相关性检验、置信区间、bootstrap/重采样等（以主文与 SI 为准）。
- **Data availability / Code availability**：与 `Essay_nc/main_manuscript.tex` 中对应段落保持一致。
- 如需 **Ethics** 声明：按模板要求填写（若使用公开平台数据且无需伦理审批，也需在模板中说明理由与限制）。

备注：当前环境网络受限，如需我自动下载模板需要你授权联网；否则建议你在浏览器手动下载后放入本目录。
