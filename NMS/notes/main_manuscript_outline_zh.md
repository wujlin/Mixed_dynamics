## 文章主线

这篇文章的核心论证不是“平台上的身份话语内容不同”这么简单，而是：

1. 平台会先组织议题可见性
2. 议题可见性会影响用户对议题的情感评价
3. 情感评价再推动评论中的身份边界取向

所以文章的因果链条是：

- `platform regime -> issue visibility -> affective evaluation -> identity-boundary orientation`

## 章节大纲

### Abstract

- 研究对象：抖音与快手
- 数据规模：约 115 万评论
- 方法组合：聚类、语义网络、监督分类、多项 logit、中介分析
- 核心发现：
  - 两个平台在上游议题生态和话语组织上差异明显
  - 但下游都存在共同机制，即 affective evaluation 起中介作用

### 1. Introduction

- 提出比较谜题：相似的身份议题，为什么在不同短视频平台上会导向不同的边界建构结果
- 回顾三类相关研究：
  - platformization / platform studies
  - affective publics
  - identity / symbolic boundaries
- 指出研究缺口：三者常并列使用，但缺少一个把“平台结构、议题生态、情感、边界工作”串起来的统一解释框架
- 提出本文贡献：
  - 建立平台化归属感的机制模型
  - 强调平台差异主要发生在上游 issue ecology
  - 将结果变量界定为可观察的 `identity-boundary orientation`

### 2. Platform Visibility, Affective Publics, and Identity-Boundary Work

- 论证平台不是中性容器，而是主动组织可见性、注意力与表达机会的基础设施
- 论证情感不是附属变量，而是决定哪些话语更能传播和被接受的评价层
- 论证身份边界不是固定身份，而是互动中持续被生产和重画的边界实践
- 提出本文的理论转向：
  - 不是直接研究“身份是什么”
  - 而是研究评论中如何呈现 integrative / neutral / conflictual 的边界取向

### 3. Theoretical Framework and Hypotheses

- 将源项目中的 `demand-power-technology` 逻辑，转写为适合 NMS 的平台比较框架
- 定义三个核心变量：
  - `issue structure`
  - `affective evaluation`
  - `identity-boundary orientation`
- 提出顺序机制：
  - 平台先塑造 issue structure
  - issue structure 影响 affective evaluation
  - affective evaluation 再影响 boundary orientation
- 提出 5 个假设：
  - H1 平台间议题结构不同
  - H2 议题结构影响情感评价
  - H3 情感评价影响边界取向
  - H4 情感评价起中介作用
  - H5 平台差异主要发生在上游生态，而不是下游中介机制

### 4. Data and Methods

- 语料规模：
  - Douyin `634,289`
  - Kuaishou `518,763`
- 聚类样本：
  - `115,305`
- 标注子样本：
  - `10,000`
- 方法流程：
  - topic clustering
  - semantic-network analysis
  - supervised labeling
  - multinomial logistic regression
  - mediation analysis

### 5. Findings

这是全文最核心的结果部分，分 3 小节。

#### 5.1 Issue structures and platform ecologies

- 抖音的议题更分散、更多元
- 快手的议题更集中，尤其集中在 `performance and revival`
- 说明平台差异首先体现在“哪些议题被反复看见”
- 进一步用不同 cluster 的 integrative / neutral / conflictual 分布说明：
  - 不同平台上的边界建构路径不同
  - 同样是 identity-related content，不同平台会导向不同的话语后果

#### 5.2 Semantic networks and discursive organization

- 通过语义网络补充说明“不是只有话题比例不同，话语连接结构也不同”
- Douyin：
  - 网络更小、更紧凑、更有局部凝聚
- Kuaishou：
  - 网络更大、更分散、语义路径更长
- 作者由此认为：
  - 抖音的话语空间更容易桥接多类议题
  - 快手更容易形成更分块、更冲突化的语义结构

#### 5.3 Multinomial logit and mediation results

- 这是机制检验部分
- 主要结论：
  - affective evaluation 是最稳定、最强的预测变量
  - 两个平台都存在“议题结构 -> 情感评价 -> 边界取向”的中介路径
- 同时平台差异仍然存在：
  - 快手某些 cluster 会更强地压低 integrative odds 或抬高 conflictual odds
  - 抖音中 commonality rhetoric 的不同表达方式，其 integrative 效果强弱不同
- 理论意义：
  - 下游情感机制较稳定
  - 上游议题生态更平台特异

### 6. Discussion

- 将结果重新放回平台研究、情感公众和边界研究三个文献脉络中解释
- 强调：
  - 平台影响并不只是“发了什么内容”
  - 更是“平台先组织了什么样的议题环境”
- 提出方法论贡献：
  - 用 `boundary orientation` 替代直接讨论“身份本身”
- 提出实践含义：
  - 平台治理不只是在删内容
  - 也包括对议题生态和互动节奏的长期塑形
- 同时承认局限：
  - 研究的是评论区，而非所有用户
  - 观察性设计不能强因果识别
  - 不同平台保留下来的模型输出完整度不同
  - 目前只分析文本，没有纳入视频的多模态维度

### 7. Conclusion

- 再次收束全文：
  - 短视频平台通过组织 issue ecologies、affective cues 和 interactional conditions，来塑造 symbolic boundaries 的协商方式
- Douyin 与 Kuaishou 的关键差别在上游可见性和话语组织
- affective evaluation 是两平台共有的稳定下游机制
- 总结性判断：
  - belonging 既不是纯心理变量，也不是纯文本变量
  - 它是被平台基础设施条件化、被情感中介、并在互动中实现的

## 一句话版

这篇文章最重要的结论是：

- 平台差异首先改变“什么议题更容易被看到、被连接、被组织”，而这些上游差异再通过情感评价，塑造评论中的身份边界取向
